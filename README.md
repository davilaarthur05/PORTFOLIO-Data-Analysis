# Melbourne Residential Solar Market Analysis

## Overview
This project is a data analytics case study investigating residential solar adoption patterns across Melbourne. Conducted as part of an IT diploma data analytics assessment, it simulates the workflow of a professional data analyst — from raw data to actionable insight.

## What It Does
- Integrates **five separate datasets** into a unified master dataframe covering **225 postcodes**
- Applies **clustering** and **Principal Component Analysis (PCA)** to identify distinct solar adoption profiles across regions
- Runs **statistical significance testing** to validate key findings
- Produces **geospatial visualisations** to communicate patterns clearly to a non-technical audience

## Tech Stack
- **Python** (pandas, scikit-learn, matplotlib, seaborn )
- Data cleaning, exploratory analysis, statistical modelling, and visual storytelling

## Notes
This is a personal/academic project developed for coursework purposes. Data has been sanitised/aggregated where appropriate.
